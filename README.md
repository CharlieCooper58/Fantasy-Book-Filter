A project dedicated to experimenting with VFX.  I implemented an anisotropic Kuwahara filter, as well as color clamps, dithering, toon shading, down scaling, sharpness, and something I can only describe as the "bad trip filter," which clamps objects' vertices to the nearest whole number along the camera's z-axis.  I created a custom script to quickly add or subtract these vfx from a stack in any order and tweak their numbers as desired.  I have new ideas for this project including fluffy trees with normal theft, so stay tuned for more.
